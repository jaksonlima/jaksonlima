### `whoami`

Arquiteto de Software e Engenheiro Sênior com foco em **sistemas distribuídos de alta performance**. Projeto plataformas guiadas por **Clean Architecture**, **Hexagonal Architecture** e **DDD**, rodando cloud-native em **GCP / GKE** com infraestrutura como código via **Terraform**. Exploro continuamente a aplicação de **IA** no ciclo de desenvolvimento de software.

- Design de APIs RESTful e event-driven
- Observabilidade ponta a ponta — logs, métricas e tracing
- DevOps, CI/CD e plataformas internas de desenvolvedor
